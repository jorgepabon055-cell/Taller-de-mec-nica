# API REST - Taller Mecánico (Fullstack)

API desarrollada con **Node.js**, **Express.js** y **MySQL** para la gestión integral de un taller automotriz, conectada a una base de datos en la nube (Railway).

---

## 🚀 Requisitos Previos
* Node.js (versión LTS recomendada)
* MySQL / Cliente de base de datos
* Gestor de paquetes npm

---
